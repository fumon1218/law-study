# 특수교육법 학습 (law-study)

특수교육 담당 장학사·학교 관리자가 법령을 **정확히 외우고 업무에 바로 쓰기 위한** 본인 전용 학습 앱입니다.
서버·로그인 없이 브라우저(아이패드 Safari 등)에서 동작하고, 학습 기록은 기기 안에만 저장됩니다.

## 지금 되는 것 (v0.5)

| 기능 | 설명 |
|---|---|
| **내장 법령** | 특수교육법, 유아교육법, 초ㆍ중등교육법, 고등교육법, 장애인복지법, 장애인차별금지법과 각 시행령·시행규칙(16종, 현행)이 앱에 들어 있어 열면 바로 조문 열람·암기. 새 버전이 배포되면 자동 반영 |
| **시행 예정 개정** | 이미 공포됐지만 시행 전인 개정(예: 2027년 시행)을 현행 조문과 분리해 표시, 부칙 원문 함께 제공 |
| 법령 가져오기 | 국가법령정보센터에서 복사한 본문을 붙여넣어 다른 법령을 직접 추가 (장·조·항·호 자동 분해) |
| 개정 비교 | 같은 법령을 다시 붙여넣으면 바뀐 조문·신설 조문을 표시하고 해당 조문을 복습 대상으로 되돌림 |
| 조문 탐색 | 목차·검색, 조문별 **원문 보기(law.go.kr)** 링크, 메모 |
| 암기 | 빈칸 채우기(기한·숫자 우선), 난이도 3단계, 간격 반복(1→3→7→14→30→60일), 오답 노트 |
| 절차·순서 | 선정·배치 같은 절차를 직접 등록해 두고 순서 맞히기 |
| **판례** | 특수교육·장애학생·학교 관리자 책임·차별 관련 판례 12건 내장. 판시사항·판결요지 먼저, 전문은 펼쳐 보기, 메모, **결론 맞히기**(간격 반복), 태그 필터 |
| **현장 대응** | 상황별 카드 15개(배치 이의, 통합교육 반대, 학대 신고, 편의제공 거절, 징계 등): 먼저 확인할 것 · 근거 조문(펼쳐 원문 보기) · 처리 순서 · 하지 말 것 · 회신 문구 틀 · 관련 판례. 근거 조문 바로 암기, 내 카드 직접 만들기 |
| **주체별 권한표** | 교육부장관·교육감·교육장·특수교육지원센터·운영위원회·학교장·보호자가 하는 일을 근거 조문과 함께 비교 |
| **통합 검색** | 16종 법령 조문·판례·현장 카드·별표 메모를 한꺼번에 검색 |
| **조문 참조 링크** | 조문 안의 "제15조", "법 제17조", 「다른 법」 제4조를 눌러 해당 조문으로 이동, 돌아가기 지원 |
| 약점 대시보드 · 기한·숫자 모드 | 자주 틀리는 조문 TOP과 법령별 진도, 숫자(기한·인원)만 가리고 연습 |
| 알림 | 곧 시행되는 개정, 시행일이 지났는데 데이터에 반영 안 된 개정, 백업 권장 |
| 백업 | 학습 기록 JSON 내보내기/가져오기 (마지막 백업일 기록) |

내장 법령의 출처와 기준 시점은 [`data/source/SOURCES.md`](data/source/SOURCES.md) 에 있습니다. 별표·서식은 포함되어 있지 않으니 「원문 보기」 링크를 이용하세요.

판례 12건은 같은 방식으로 `data/source/cases/` 에 원문을 두고 `python3 scripts/build_cases.py` 로 변환·글자 단위 검증합니다. 한계: 직접 관련 판례가 많지 않고 헌법재판소 결정은 없으며, 분류 태그는 앱이 임의로 붙인 것입니다. 참조조문의 조 번호는 **판결 당시 기준**이라 현행과 다를 수 있어 법령 단위로만 연결합니다.

## 사용법

1. 앱을 열면 내장 법령 16종이 자동으로 불러와집니다. **조문** 탭에서 바로 볼 수 있습니다.
2. **암기** 탭에서 오늘 학습을 시작합니다. (하루 새 조문 수는 관리 탭에서 조정)
3. 다른 법령은 국가법령정보센터에서 본문을 복사해 **관리 → 법령 가져오기**에 붙여넣어 추가합니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 로 설정하면
`https://<계정>.github.io/law-study/` 에서 열립니다. 아이패드 Safari에서 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 개발

```bash
python3 scripts/fetch_sources.py # legalize-kr 클론 → data/source/*.md (현행+시행 예정, 시행 전 개정 분리)
python3 scripts/build_field.py  # 현장 카드·권한표 → data/field/situations.json
python3 scripts/check_field.py  # 카드가 인용한 조문·판례가 내장 데이터에 실제 있는지 검증
python3 scripts/build_cases.py  # data/source/cases/*.md → data/cases/*.json + 원문 대조 검증
python3 scripts/build_data.py   # data/source/*.md → data/laws/*.json 변환 + 원문 대조 검증
node tests/core.test.cjs        # 파서·빈칸·간격 반복 단위 테스트
python3 tests/ui_smoke.py       # 브라우저 흐름 테스트 (playwright 필요, 가상 법령 텍스트 사용)
python3 -m http.server 8000     # 로컬 실행
```

## 로드맵

1. 법령 추가 확장(교육기본법, 교육공무원법 등), 별표 내용 보강
2. 주체별 권한 카드·비교표, 개정 알림 자동화(국가법령정보센터 Open API, 인증키 OC 필요)
3. **현장 대응 모드**: 상황 → 근거 조문 카드, 지도·점검 체크리스트, 민원 회신 문구 틀
4. 판례 업무 시사점 카드, 현장 카드 확충(자주 겪는 민원 반영), 헌법재판소 결정

> AI가 만든 요약·응대 예시는 모두 「참고용」으로 표시하고 원문 링크를 함께 둡니다.

## 현장 대응 카드에 대해

카드의 상황·처리 순서·회신 문구 틀은 앱이 정리한 **참고용 초안**입니다(법적 판단이나 유권해석 아님). 근거 조문은 앱에 내장된 원문에서 직접 확인했고
`scripts/check_field.py` 가 인용한 조문·판례가 실제로 있는지 검사합니다. 교육청별 지침이나 사안별 사정은 반영되어 있지 않으므로 반드시 소속 기관의 지침과 원문을 확인하세요.
