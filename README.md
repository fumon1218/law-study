# 특수교육법 학습 (law-study)

특수교육 담당 장학사·학교 관리자가 법령을 **정확히 외우고 업무에 바로 쓰기 위한** 본인 전용 학습 앱입니다.
서버·로그인 없이 브라우저(아이패드 Safari 등)에서 동작하고, 학습 기록은 기기 안에만 저장됩니다.

## 지금 되는 것 (v0.2)

| 기능 | 설명 |
|---|---|
| **내장 법령** | 특수교육법·시행령·시행규칙(현행)이 앱에 들어 있어 열면 바로 조문 열람·암기. 새 버전이 배포되면 자동 반영 |
| **시행 예정 개정** | 이미 공포됐지만 시행 전인 개정(예: 2027년 시행)을 현행 조문과 분리해 표시, 부칙 원문 함께 제공 |
| 법령 가져오기 | 국가법령정보센터에서 복사한 본문을 붙여넣어 다른 법령을 직접 추가 (장·조·항·호 자동 분해) |
| 개정 비교 | 같은 법령을 다시 붙여넣으면 바뀐 조문·신설 조문을 표시하고 해당 조문을 복습 대상으로 되돌림 |
| 조문 탐색 | 목차·검색, 조문별 **원문 보기(law.go.kr)** 링크, 메모 |
| 암기 | 빈칸 채우기(기한·숫자 우선), 난이도 3단계, 간격 반복(1→3→7→14→30→60일), 오답 노트 |
| 절차·순서 | 선정·배치 같은 절차를 직접 등록해 두고 순서 맞히기 |
| 백업 | 학습 기록 JSON 내보내기/가져오기 |

내장 법령의 출처와 기준 시점은 [`data/source/SOURCES.md`](data/source/SOURCES.md) 에 있습니다. 별표·서식은 포함되어 있지 않으니 「원문 보기」 링크를 이용하세요.

## 사용법

1. 앱을 열면 특수교육법·시행령·시행규칙이 자동으로 불러와집니다. **조문** 탭에서 바로 볼 수 있습니다.
2. **암기** 탭에서 오늘 학습을 시작합니다. (하루 새 조문 수는 관리 탭에서 조정)
3. 다른 법령은 국가법령정보센터에서 본문을 복사해 **관리 → 법령 가져오기**에 붙여넣어 추가합니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 로 설정하면
`https://<계정>.github.io/law-study/` 에서 열립니다. 아이패드 Safari에서 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 개발

```bash
python3 scripts/build_data.py   # data/source/*.md → data/laws/*.json 변환 + 원문 대조 검증
node tests/core.test.cjs        # 파서·빈칸·간격 반복 단위 테스트
python3 tests/ui_smoke.py       # 브라우저 흐름 테스트 (playwright 필요, 가상 법령 텍스트 사용)
python3 -m http.server 8000     # 로컬 실행
```

## 로드맵

1. 법령 확장: 장애인복지법, 장애인차별금지법, 초·중등교육법 (같은 방식으로 내장)
2. 주체별 권한 카드·비교표, 개정 알림 자동화(국가법령정보센터 Open API, 인증키 OC 필요)
3. **현장 대응 모드**: 상황 → 근거 조문 카드, 지도·점검 체크리스트, 민원 회신 문구 틀
4. 판례 예습(결론 맞히기 + 업무 시사점), 약점 대시보드

> AI가 만든 요약·응대 예시는 모두 「참고용」으로 표시하고 원문 링크를 함께 둡니다.
